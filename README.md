# Romanian TTS Trainer

Локальное Python-приложение для многократного прослушивания и повторения румынских предложений. Интерфейс открывается в браузере, а MP3 создаются внешним онлайн-движком Microsoft Edge TTS через Python-пакет `edge-tts`.

## Возможности

- одна фраза на строку;
- необязательный русский перевод после `|` или Tab;
- румынские женский и мужской голоса;
- настройка скорости, высоты голоса и паузы;
- 1, 2, 3, 5, 10 или бесконечное число повторов;
- повтор всего списка;
- скрытие перевода для самопроверки;
- локальный кеш MP3: уже озвученные фразы работают без повторного запроса;
- сохранение текста и настроек в браузере;
- готовые предложения первой недели.

## Установка в Arch Linux

Распакуйте архив и перейдите в каталог проекта:

```bash
cd romanian_tts_trainer
```

Установите Python, если он ещё не установлен:

```bash
sudo pacman -S python python-pip
```

Создайте отдельное окружение и установите единственную зависимость:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

## Запуск

```bash
python app.py
```

Откроется `http://127.0.0.1:8765`. Для остановки нажмите `Ctrl+C` в терминале.

Если браузер открывать автоматически не нужно:

```bash
python app.py --no-browser
```

## Как добавлять предложения из чата

Скопируйте подготовленный блок в поле приложения. Поддерживаются два формата:

```text
Bună ziua.
Mă numesc Oleh.
```

или с переводом:

```text
Bună ziua. | Добрый день.
Mă numesc Oleh. | Меня зовут Олег.
```

Нажмите **«Обновить список»**, выберите голос и число повторов, затем **«Воспроизвести»**.

## Интернет и кеш

Интернет необходим при первом создании аудио для новой фразы или после изменения голоса, скорости либо высоты. Результат сохраняется в `cache/audio/`; при следующих запусках он используется локально.

`edge-tts` не требует API-ключа, но использует внешний онлайн-сервис. Поэтому его доступность зависит от сети и изменений на стороне поставщика. Приложение привязано только к `127.0.0.1` и не публикуется в локальную сеть.

## Проверка проекта

Тесты используют имитацию TTS и не требуют интернета:

```bash
python -m unittest discover -s tests -v
```
