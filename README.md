# Romanian TTS Trainer

Локальное Python-приложение для изучения румынских фраз: повторное прослушивание через Microsoft Edge TTS и запоминающиеся визуальные ассоциации через Cloudflare Workers AI (`FLUX.1 Schnell`).

## Что умеет

- одна фраза на строку;
- одна крупная карточка остаётся на месте и меняется во время прогона — страница не прыгает между карточками;
- компактный плейлист прокручивается только внутри своей панели;
- русский перевод рядом с румынской фразой;
- динамический список румынских голосов Edge TTS;
- скорость, высота голоса, пауза и число повторов;
- повтор всего списка и мгновенная остановка;
- режим «Вспомнить по картинке», скрывающий фразу, перевод, редактор и плейлист до показа ответа;
- локальный кеш MP3 и изображений;
- генерация ассоциативных изображений через `FLUX.1 Schnell`;
- автоматическое приведение генераций к компактному JPEG 300 × 300;
- пакетная генерация только для карточек без изображения;
- отдельные ссылки на Google Images, Bing Images и Openverse без поискового API;
- вставка изображения прямо из буфера обмена через `Ctrl+V`;
- drag & drop изображения в окно выбора;
- выбор JPEG/PNG/WebP/GIF с компьютера;
- загрузка изображения по прямой `http://` или `https://` ссылке;
- одно активное изображение на румынскую фразу: смена идеи образа его не сбрасывает;
- удаление/замена текущего изображения;
- кнопка добавления/замены появляется поверх картинки только при наведении курсора или фокусе с клавиатуры;
- отдельная идея визуального образа для каждой карточки.

## Формат фраз

```text
Română | Русский | visual association
```

Третий столбец необязателен. Для базового набора уже добавлены короткие английские идеи образов, например:

```text
Nu am înțeles. | Я не понял. | confused person question mark
```

Если идея отсутствует, приложение использует готовый вариант для встроенных фраз, а для остальных — русский перевод или саму румынскую фразу.

## Установка в Arch Linux

```bash
sudo pacman -S python python-pip

git clone https://github.com/olegs18/romanian_tts_trainer.git
cd romanian_tts_trainer
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

### Опционально: генерация через Cloudflare Workers AI

Без Cloudflare приложение продолжает озвучивать фразы и принимать изображения из буфера, файла или URL. Для генерации ассоциаций:

1. Создайте бесплатный аккаунт Cloudflare.
2. Скопируйте **Account ID** из панели Cloudflare.
3. Создайте API Token с разрешениями **Workers AI — Read** и **Workers AI — Edit**.
4. Скопируйте пример настроек:

```bash
cp .env.example .env
```

5. Заполните `.env`:

```text
CLOUDFLARE_ACCOUNT_ID=...
CLOUDFLARE_API_TOKEN=...
```

Перезапустите приложение. Токен остаётся на локальном Python-сервере и не передаётся JavaScript-коду браузера.

Модель: [`@cf/black-forest-labs/flux-1-schnell`](https://developers.cloudflare.com/workers-ai/models/flux-1-schnell/). Бесплатная квота Cloudflare Workers AI сейчас составляет 10 000 neurons в сутки; актуальные условия смотрите на [странице тарифов](https://developers.cloudflare.com/workers-ai/platform/pricing/).

## Как работают картинки

Наведите курсор на область изображения большой карточки: появится кнопка **«Добавить изображение»** или **«Заменить изображение»**. При работе с клавиатуры она появляется при фокусе; на сенсорном экране остаётся видимой.

В диалоге доступны пять способов:

1. **FLUX.1 Schnell** — введите идею образа и нажмите **«Сгенерировать и прикрепить»**. Приложение усиливает идею правилами мнемонического изображения, запрещает текст на картинке и сохраняет результат как JPEG 300 × 300.
2. **Поиск в браузере** — ссылки открывают Google Images, Bing Images или Openverse с запросом текущей карточки. Это обычные ссылки, поэтому `GOOGLE_CSE_ID` и поисковые API не нужны.
3. **Буфер обмена** — скопируйте картинку в браузере или другом приложении и нажмите `Ctrl+V` в открытом диалоге.
4. **Файл** — нажмите **«Выбрать изображение»** либо перетащите файл в область drag & drop.
5. **URL** — вставьте прямую `http://`/`https://` ссылку и нажмите **«Загрузить»**.

Поддерживаются JPEG, PNG, WebP и GIF размером до **12 МБ**. Файл проверяется не только по расширению/MIME, но и по сигнатуре содержимого.

Картинка сохраняется в `cache/images/` и привязывается к **румынской фразе**, а не к идее образа. Поэтому описание можно менять, не теряя уже прикреплённую ассоциацию.

Для URL сервер блокирует `localhost`, loopback/private/link-local адреса и неподдерживаемые типы файлов. Скачанный файл кешируется локально, поэтому затем исходный URL для показа не нужен.

Кнопка **«Удалить изображение»** удаляет активное изображение карточки. Кнопка **«Сгенерировать недостающие»** последовательно обращается к FLUX только для фраз без картинки; процесс можно остановить после текущей генерации.

При замене файла адрес картинки получает новую версию. Поэтому браузер сразу показывает обновлённое изображение, даже если старый вариант уже находился в кеше.

## Интернет и кеш

Интернет нужен:

- при первом создании аудио для новой комбинации «фраза + голос + скорость + высота»;
- при генерации новой ассоциации через Cloudflare;
- при открытии ссылок поиска в браузере;
- при загрузке изображения по URL.

После кеширования MP3 и выбранные изображения работают локально.

## Тесты

Тесты не делают реальных запросов к TTS или Cloudflare:

```bash
python -m unittest discover -s tests -v
npm ci --ignore-scripts
npm test
```

Node.js нужен только для тестов интерфейса, но не для запуска приложения.
