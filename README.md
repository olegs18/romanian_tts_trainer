# Romanian TTS Trainer

Локальное Python-приложение для изучения румынских фраз: повторное прослушивание через Microsoft Edge TTS и визуальные ассоциации, **найденные в сети**, а не сгенерированные.

## Что умеет

- одна фраза на строку;
- русский перевод рядом с румынской фразой;
- динамический список румынских голосов Edge TTS;
- скорость, высота голоса, пауза и число повторов;
- повтор всего списка и мгновенная остановка;
- локальный кеш MP3;
- поиск картинок через Openverse без API-ключа;
- опциональный поиск через Google Images API, если у вас уже есть Google Custom Search JSON API key + Search Engine ID;
- отдельная кнопка «Открыть Google Images» даже без API;
- вставка изображения прямо из буфера обмена через `Ctrl+V`;
- drag & drop изображения в окно выбора;
- выбор JPEG/PNG/WebP/GIF с компьютера;
- загрузка изображения по прямой `http://` или `https://` ссылке;
- до 12 кандидатов на каждую фразу и ручной выбор наиболее запоминающейся картинки;
- автоматический подбор первого релевантного результата для всех карточек без картинки;
- локальный кеш выбранной картинки;
- одно активное изображение на румынскую фразу: смена поискового запроса его не сбрасывает;
- удаление/замена текущего изображения;
- сохранение автора, лицензии и ссылки на источник для результатов Openverse;
- отдельный поисковый запрос для каждой карточки — его можно менять вручную.

Openverse используется потому, что он индексирует открыто лицензированные изображения. В отличие от парсинга Google/Bing Images это публичный API и не требует хрупкого HTML-скрейпинга.

## Формат фраз

```text
Română | Русский | image search query
```

Третий столбец необязателен. Для базового набора уже добавлены специально подобранные английские запросы, например:

```text
Nu am înțeles. | Я не понял. | confused person question mark
```

Если поисковый запрос отсутствует, приложение использует готовый запрос для встроенных фраз, а для остальных — русский перевод или саму румынскую фразу.

## Установка в Arch Linux

```bash
sudo pacman -S python python-pip

git clone https://github.com/olegs18/romanian_tts_trainer.git
cd romanian_tts_trainer
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

### Опционально: Google Images внутри приложения

Если у вас уже есть доступ к **Google Custom Search JSON API**, скопируйте пример настроек:

```bash
cp .env.example .env
```

и заполните:

```text
GOOGLE_CSE_API_KEY=...
GOOGLE_CSE_ID=...
```

После перезапуска приложения режим **Авто** будет предпочитать Google Images, а Openverse останется доступен вручную.

Важно: Google закрыл Custom Search JSON API для новых клиентов; существующие клиенты могут использовать его до 1 января 2027 года. Поэтому без уже выданных credentials приложение не пытается скрейпить HTML Google Images — вместо этого есть кнопка **«Открыть Google Images»**, после чего найденную картинку можно вставить через `Ctrl+V`, drag & drop, файл или URL.

## Как работают картинки

У каждой карточки есть кнопка **«Добавить / заменить»**. В одном диалоге доступны четыре способа:

1. **Openverse** — приложение показывает до 12 открыто лицензированных изображений, после чего можно выбрать подходящее.
2. **Буфер обмена** — скопируйте картинку в другом приложении или браузере и нажмите `Ctrl+V` в открытом диалоге.
3. **Файл** — нажмите **«Выбрать фото»** либо перетащите изображение в область drag & drop.
4. **URL** — вставьте прямую `http://`/`https://` ссылку и нажмите **«Загрузить»**.

Поддерживаются JPEG, PNG, WebP и GIF размером до **12 МБ**. Файл проверяется не только по расширению/MIME, но и по сигнатуре содержимого.

Выбранная картинка сохраняется в `cache/images/` и привязывается к **румынской фразе**, а не к поисковому запросу. Поэтому запрос картинки можно менять, не теряя уже выбранную ассоциацию.

Для URL сервер блокирует `localhost`, loopback/private/link-local адреса и неподдерживаемые типы файлов. Скачанный файл кешируется локально, поэтому затем исходный URL для показа не нужен.

Кнопка **«Удалить текущее»** удаляет активное изображение карточки. Кнопка **«Автоподобрать недостающие»** по-прежнему выбирает первый результат Openverse только для карточек без картинки.

### Почему сохраняются автор и лицензия

Картинки из Openverse имеют разные открытые лицензии. Поэтому приложение сохраняет рядом с выбранным изображением атрибуцию и ссылку на исходную страницу. Не удаляйте эти данные, если изображение используется за пределами личного тренажёра.

## Интернет и кеш

Интернет нужен:

- при первом создании аудио для новой комбинации «фраза + голос + скорость + высота»;
- при поиске новой картинки;
- при выборе картинки в Openverse, пока она не скачана в локальный кеш;
- при загрузке изображения по URL.

После кеширования MP3 и выбранные изображения работают локально.
