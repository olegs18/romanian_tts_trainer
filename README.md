# Romanian TTS Trainer

Локальное Python-приложение для изучения румынских фраз: повторное прослушивание через Microsoft Edge TTS и визуальные ассоциации, **найденные в сети**, а не сгенерированные.

## Что умеет

- одна фраза на строку;
- русский перевод рядом с румынской фразой;
- динамический список румынских голосов Edge TTS;
- скорость, высота голоса, пауза и число повторов;
- повтор всего списка и мгновенная остановка;
- локальный кеш MP3;
- поиск картинок через Openverse без API-ключа;
- до 12 кандидатов на каждую фразу и ручной выбор наиболее запоминающейся картинки;
- автоматический подбор первого релевантного результата для всех карточек без картинки;
- локальный кеш выбранной картинки;
- сохранение автора, лицензии и ссылки на источник;
- отдельный поисковый запрос для каждой карточки — его можно менять вручную.

Openverse используется потому, что он индексирует открыто лицензированные изображения. В отличие от парсинга Google/Bing Images это публичный API и не требует хрупкого HTML-скрейпинга.

## Формат фраз

```text
Română | Русский | image search query
```

Третий столбец необязателен. Для базового набора уже добавлены специально подобранные английские запросы, например:

```text
Nu am înțeles. | Я не понял. | confused person question mark
```

Если поисковый запрос отсутствует, приложение использует готовый запрос для встроенных фраз, а для остальных — русский перевод или саму румынскую фразу.

## Установка в Arch Linux

```bash
sudo pacman -S python python-pip

git clone https://github.com/olegs18/romanian_tts_trainer.git
cd romanian_tts_trainer
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

## Запуск

```bash
python app.py
```

Браузер откроет:

```text
http://127.0.0.1:8765
```

Без автоматического открытия браузера:

```bash
python app.py --no-browser
```

## Как работают картинки

1. Нажмите **«Найти»** на карточке.
2. Сервер выполняет поиск в Openverse.
3. Приложение показывает до 12 картинок с автором и лицензией.
4. Выберите наиболее сильную ассоциацию.
5. Выбранная картинка скачивается в `cache/images/` и дальше показывается локально.
6. Для другого варианта нажмите **↻**.

Кнопка **«Автоподобрать недостающие»** проходит по карточкам без картинки и выбирает первый результат Openverse. Это удобно для быстрого заполнения, но ручной выбор обычно лучше для запоминания.

### Почему сохраняются автор и лицензия

Картинки из Openverse имеют разные открытые лицензии. Поэтому приложение сохраняет рядом с выбранным изображением атрибуцию и ссылку на исходную страницу. Не удаляйте эти данные, если изображение используется за пределами личного тренажёра.

## Интернет и кеш

Интернет нужен:

- при первом создании аудио для новой комбинации «фраза + голос + скорость + высота»;
- при поиске новой картинки;
- при выборе картинки, пока она не скачана в локальный кеш.

После кеширования MP3 и выбранные изображения работают локально.
